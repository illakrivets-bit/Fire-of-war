# Map assets

Place the two source GeoJSON files in this directory:

- `ukraine_adm1.geojson`
- `russia_adm1.geojson`

See [MAP_DATA_SOURCES.md](../../docs/MAP_DATA_SOURCES.md) for source metadata, download instructions, vintage, and licensing notes.

The scene will run without the data files, but it will show a missing-data status instead of drawing the map.
